# תיקיית קליטה לסריקות גולמיות

לכאן מעלים את **קבצי הסריקה המקוריים**, בלי לגעת בהם ובלי להקטין —
הסקריפט `npm run photos` הוא שיעשה את היישור, החיתוך וההקטנה.

התמונות המוכנות ייכתבו ל-`public/images/...`, והתיקייה הזאת תימחק
מהענף לפני שהוא ממוזג ל-main — כדי שהקבצים הכבדים לא יישארו
בהיסטוריה של הרפוזיטורי ולא ייכנסו לאתר.

**אל תמזגו את הענף הזה ל-main כל עוד יש כאן קבצים.**

## איך מעלים

דרך הדפדפן: בעמוד הענף → `Add file` → `Upload files` → גוררים את הקבצים.
אפשר לגרור הרבה קבצים יחד (עד 100 בכל העלאה, עד 25MB לקובץ).

## הערות

- פורמט: JPEG או TIFF ישירות מהסורק, 300–600 DPI. אין צורך לחתוך מראש.
- אפשר להשאיר כמה תמונות על אותה סריקה — הסקריפט יודע לפצל (`--split`).
- שמות קבצים בעברית תקינים לגמרי.
- אפשר לחלק לתת-תיקיות לפי אלבום (למשל `_scans/צבא/`, `_scans/חתונה/`).
